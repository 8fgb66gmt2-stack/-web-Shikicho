# -web-Shikicho
日ノ本帝國・四季庁の公式サイトです

## 第三次大型拡張

- `astrarium.html`: 四季神祇天象儀
- `registry.html`: 人物・神籍・組織・公文書の横断臺帳
- `facilities.html`: 本廳舎・庁内機能配置案内
- `investigation.html`: 諸廳合同・極秘調査室
- `shiki-third-data.js` / `shiki-third.js`: 公開情報索引とブラウザ内機能
- `shiki-third.css` / `shiki-home-astrarium.css`: 共通意匠と天象儀表示

閲覧履歴・お気に入り・調査進捗・仮想閲覧者証はブラウザ内に保存されます。GitHub Pagesは静的サイトのため、実際の認証・権限管理・機密保護は提供しません。公開情報の詳細は `docs/QUALITY_AUDIT.md` を参照してください。

## 第四次大型拡張

- `portal.html`: 総合行政ポータル
- `laws.html`: 法令・官報閲覧室
- `organization.html`: 組織・官職データベース
- `chronicle.html`: 公開資料に基づく歴史年表
- `worship.html`: 四季神祇・神籍案内
- `yearbook.html`: 公開索引の登録件数・統計閲覧室
- `network.html`: 行政情報の相互参照ネットワーク
- `search.html`: 人物・組織・神籍・施設・公文書の統合検索
- `shiki-fourth-data.js` / `shiki-fourth.js`: 年表・関係索引と各画面の操作層
- `shiki-fourth.css`: 象牙色・古金・臙脂による共通意匠

第四次の年表・統計は既存公開資料と索引件数に限定し、未記載の日付・人事・実勢統計を創作していません。相互参照・閲覧演出は静的サイト上のブラウザ内機能です。

## 第五次大型拡張：行政統合管制室

- `command-center.html`: 公開索引・人物・組織・神籍・公文書・年表を束ねる統合管制室。
- `command-center.css`: 象牙・古金・臙脂・深緑を継承した管制室専用レイアウト。PC・タブレット・スマートフォンに対応。
- `command-center.js`: 登録件数盤、分類横断検索、関係図、原資料への導線、年表表示、既存臺帳と共通の保存資料連携。
- 本廳トップと総合行政ポータルから管制室へ移動できます。
- 現在時代の表示を玲瓏108年に統一。玲瓏元年＝帝國暦133年という歴史ページの換算に従い、現行帝國暦表記を240年へ整合しました。帝國暦二三六年・二三七年などの過去資料は変更していません。

管制室の件数・関係は既存の公開索引を集計・再表示するもので、新しい人事・出来事・観測数値を創作していません。保存資料は既存の `shikiThirdFavourites` を共有します。静的サイトのため、実認証・権限管理・機密保護を提供するものではありません。
