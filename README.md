# -web-Shikicho
日ノ本帝國・四季庁の公式サイトです

## 第三次大型拡張

- `astrarium.html`: 四季神祇天象儀
- `registry.html`: 人物・神籍・組織・公文書の横断臺帳
- `facilities.html`: 本廳舎・庁内機能配置案内
- `investigation.html`: 諸廳合同・極秘調査室
- `shiki-third-data.js` / `shiki-third.js`: 公開情報索引とブラウザ内機能
- `shiki-third.css` / `shiki-home-astrarium.css`: 共通意匠と天象儀表示

閲覧履歴・お気に入り・調査進捗・仮想閲覧者証はブラウザ内に保存されます。GitHub Pagesは静的サイトのため、実際の認証・権限管理・機密保護は提供しません。公開情報の詳細は `docs/QUALITY_AUDIT.md` を参照してください。
