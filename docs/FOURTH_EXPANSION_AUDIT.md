# 第四次大型拡張・品質監査記録

## 実装範囲
- 総合行政ポータル（portal.html）
- 法令・官報閲覧室（laws.html）
- 組織・官職データベース（organization.html）
- 公開資料に基づく帝國歴史年表（chronicle.html）
- 四季神祇・神籍案内（worship.html）
- 公開索引の登録件数を示す年鑑・統計閲覧室（yearbook.html）
- 行政情報相互参照ネットワーク（network.html）
- 統合行政情報検索（search.html）
- 共通意匠・索引・操作層（shiki-fourth.css / shiki-fourth-data.js / shiki-fourth.js）

## 設計上の保全事項
- 第三次拡張の天象儀・行政情報臺帳・施設案内・合同調査室を削除していない。
- 既存の神籍・人物・組織・資料のデータを shiki-third-data.js から参照する。
- 年表は既存の第十五號・第十八號・第十九號および官報237.07.15、237.08.20、237.09.02の記載に限定する。
- 年鑑は公開索引の登録件数のみを表示し、帝國全体の実勢統計と誤認させない。
- 組織階層は既存公開組織情報の所管関係を表し、未掲載の内部指揮系統や職員を追加しない。
- 閲覧者証・閲覧履歴・封緘演出は静的サイトのブラウザ内機能であり、認証・機密保護ではない。

## 実施した静的検査

- 新規JavaScriptの構文検査。
- 新規CSSの波括弧対応検査。
- HTMLのID重複検査。
- 主要ページからの総合ポータル・統合検索への導線を確認。
